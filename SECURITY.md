# Security Policy

Please do not open a public issue for a vulnerability that could expose API keys, subscription entitlements, note contents, or cloud spending. Send a private report through GitHub Security Advisories for this repository with reproduction steps and impact.

No production secret belongs in this repository. Quick cleanup can store a user-provided Groq key in the device Keychain. Personal-key style polish can store an OpenRouter key the same way. Cloud polish is authorized with an App Store subscription transaction.
